# 公開範圍

公開專案提供注音解析、詞庫、decoder、通用語言模型、語料授權稽核、評估介面與已發布的歷史結果。

產品排序模型的訓練、資料組成、權重與載入、部署設定、Windows 輸入法整合、個人化，以及未完成封存評估的測試資料均保留在私密專案。

公開核心可被私密產品引用。公開核心不依賴私密產品；舊研究工具中選用 teacher 的功能在公開版停用。第三方原始語料與產生的模型 artifact 依各來源條款自行取得，不隨本版散布。

PUBLIC_DISTRIBUTION.json 提供逐檔雜湊、排除類別與稽核紀錄。歷史 sealed TEST-V1 已發布；後續正式 benchmark 會在封存評估完成後另行發布。
